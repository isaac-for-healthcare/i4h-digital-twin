# Patient digital twin tutorials

Longer, end-to-end walkthroughs that combine the `patient_digital_twin` API with
model backends. For single-call usage see the [package README](../README.md) and the
[examples](../examples/README.md).

| Tutorial | What it shows |
| --- | --- |
| [Cohort generation](cohort_generation/README.md) | Sample patients (sex, age, height, BMI) from literature-based distributions, generate each CT with NV-Generate-CTMR conditioned on its characteristics, build and export every patient twin, and quality-check the cohort ([500-patient report](cohort_generation/REPORT.md)) |
